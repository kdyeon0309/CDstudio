# CDstudio 💿

음원 추출, 트랙 편집, 표지 제작, 실치수 인쇄, 오디오 CD 굽기를 한곳에서 진행하는 한국어 로컬 웹앱입니다. 각 사용자가 자기 Mac에서 실행하는 **1인·개인 소장용** 도구이며 공개 서버 배포나 앨범 공유 기능은 제공하지 않습니다.

앨범은 파일시스템에 저장하며 별도 DB가 필요하지 않습니다. 웹앱의 로컬 서버는 실행해야 하고, 음원 다운로드와 AI 생성에는 인터넷 및 해당 서비스 접근 권한이 필요합니다.

## 준비물

| 항목 | 용도 |
| --- | --- |
| Apple Silicon Mac + Homebrew | 현재 외부 도구 경로가 `/opt/homebrew/bin/`으로 고정되어 있습니다. Intel Mac·Windows·Linux는 그대로 실행하는 지원 대상이 아닙니다. |
| Node.js 22 이상, npm, Git | 앱 설치·실행 |
| Python 3.10 이상, ffmpeg | yt-dlp 실행 및 오디오·이미지 변환. ffprobe도 함께 필요합니다. |
| ChatGPT 계정으로 로그인된 Codex CLI | 이미지 생성 및 기본 HTML 디자인 엔진에 필요합니다. 직접 이미지 업로드에는 필요하지 않습니다. |
| 광학 드라이브와 공 CD-R/CD-RW | 실제 CD 굽기에만 필요합니다. 다른 작업은 드라이브 없이 사용할 수 있습니다. |
| 프린터 또는 PDF 저장 | 실치수 표지 출력 |

AI에는 이미지 도구를 지원하는 CLI·계정이 필요합니다. 로그인만으로 생성 성공을 보장하지는 않습니다. 이미지 스튜디오는 별도 API 키나 Gemini 연결을 사용하지 않습니다.

## 설치 및 실행

Homebrew와 Node.js를 준비한 뒤 터미널에서 실행하세요.

```bash
git clone https://github.com/kdyeon0309/CDstudio.git
cd CDstudio
brew install python ffmpeg
npm ci
npm run setup:yt-dlp
npm run check:yt-dlp
npm run dev -- --hostname 127.0.0.1
```

브라우저에서 `http://localhost:3000`을 열고, 사용하는 동안 터미널의 서버를 켜두세요. 종료는 `Ctrl+C`입니다. 로컬에서만 접근하도록 `--hostname 127.0.0.1`을 지정합니다. 다중 사용자 인증을 갖춘 서비스가 아니므로 외부 네트워크에 공개하지 마세요.

설치 스크립트는 공식 yt-dlp **2026.08.19**를 프로젝트의 `.tools/`에 내려받아 SHA256과 버전을 검증합니다. 앱은 Homebrew의 전역 yt-dlp 대신 이 검증된 파일을 사용합니다.

AI를 사용하려면 Codex CLI를 준비하고 ChatGPT 계정으로 로그인하세요. 앱 서버를 실행하는 터미널에서 설치·로그인 상태를 확인할 수 있습니다.

```bash
codex --version
codex login status
```

## 처음 만드는 순서

1. **라이브러리:** 앨범을 만들고 제목·아티스트를 입력합니다. 기존 앨범 정보도 수정할 수 있습니다.
2. **추출·트랙 편집:** YouTube/SoundCloud URL로 음원을 가져오고 곡명·순서·트랙 간격을 정리합니다.
3. **디자인:** 영역별 AI 생성 또는 직접 업로드를 선택합니다. 원하는 후보의 `이 후보 사용`을 눌러 적용합니다.
4. **완성 CD:** 선택한 표지·스파인·라벨을 케이스에 조립한 모습을 확인합니다.
5. **인쇄:** A4 미리보기에서 겉·속 표지와 재단·접기 위치를 확인한 뒤 출력하거나 PDF로 저장합니다.
6. **굽기:** 드라이브와 공매체를 연결하고 트랙 목록·용량을 확인한 뒤 확인 모달에서 실행합니다. 실제 굽기는 매체를 소모할 수 있습니다.

음원은 **44.1kHz / 16bit / 스테레오 WAV**로 변환합니다. 굽기 전에 실제 WAV와 트랙 간격을 다시 검사하며 **79분을 초과하면 차단**합니다. CD 규격으로 변환해도 스트리밍 원본 이상의 음질로 복원되지는 않습니다.

## 영역별 표지 만들기

앞표지, 앞표지 내부, 뒷표지 중앙, 접히는 스파인, 뒷표지 내부, CD 라벨을 각각 작업합니다. 다른 영역의 선택을 유지하며 서로 다른 영역은 동시에 생성할 수 있습니다.

- **직접 업로드:** PNG·JPEG·WebP를 규격에 맞게 자르거나 전체가 보이도록 배치하고 위치·확대를 조절합니다. 원본은 보존합니다. AI 생성·업로드·빈 영역을 섞어 사용할 수 있습니다.
- **참고 이미지:** 사진마다 `인물`, `배경` 같은 임시 이름을 붙이고 프롬프트에서 그 이름으로 지시합니다. 실제 파일명은 바꾸지 않습니다.
- **추천 프롬프트:** 영역별 5개, 총 30개 초안을 제공합니다. 선택만으로 생성이 시작되지는 않으며 내용을 수정한 뒤 실행할 수 있습니다.
- **후보와 조합:** 새 결과는 후보로 저장되고 현재 선택을 자동으로 덮어쓰지 않습니다. 원하는 후보를 적용하거나 조합을 세트로 저장·복원하세요.
- **글자:** 제목·아티스트·트랙리스트를 이미지에 요청할 수 있지만 철자·순서·선명도를 확인해야 합니다. 별도 인쇄 글자 표시 기능은 앨범에 등록된 정보를 사용하며 프롬프트 목록을 자동으로 가져오지 않습니다.

이미지 스튜디오의 프롬프트에는 4,000자 제한이 없습니다. 요청 본문이 1MiB를 넘으면 자르지 않고 오류를 표시합니다. 전달한 세부 지시가 모두 결과에 반영된다는 보장은 없습니다.

업로드는 한 번에 최대 5파일, 파일당·요청 전체 최대 20MB입니다. 이는 업로드 요청 제한이며 이미 업로드한 AI 참고 이미지 선택을 4장으로 제한하는 것은 아닙니다. 업로드 후보는 변환 과정에서 원본과 픽셀 크기가 달라질 수 있습니다.

AI에는 300PPI 인쇄 목표를 요청하지만 출력 크기·글자 품질을 강제할 수 없습니다. 화면의 실제 픽셀 크기와 추정 PPI 경고를 확인하세요. 크게 확대하면 흐려질 수 있으며 낮은 해상도를 확대 저장한다고 세부묘사가 복원되지는 않습니다.

이미지·기존 디자인 생성과 음원 추출은 서버 작업입니다. **화면 이동·새로고침·탭 닫기 후에도 이미 접수된 작업은 계속**되고, 돌아오면 상태를 다시 조회합니다. 중단 버튼은 해당 작업만 취소합니다. 단, **서버 종료·재시작 후 자동 재개는 지원하지 않습니다.**

기존 HTML 디자인 화면은 별도로 유지됩니다. 기본 엔진은 Codex이며 Claude는 환경변수로 명시적으로 선택합니다. 이미지 스튜디오 실패 시 Claude로 자동 전환하는 기능은 아닙니다.

## 인쇄와 조립

| 부품 | 완성 치수 |
| --- | --- |
| 앞표지·앞표지 내부 | 각각 120 × 120mm |
| 뒷표지 중앙 | 137 × 118mm, 스파인 제외 |
| 뒷표지 전체 | 150 × 118mm, 양쪽 6.5mm 스파인 포함 |
| CD 인쇄 라벨 | 바깥지름 116mm / 안쪽지름 23mm |

앞표지와 내부가 모두 준비되면 한 장에 **좌우로**, 뒷표지와 내부는 한 장에 **위아래로** 출력해 접을 수 있습니다. 양면 인쇄 대신 한 장을 접어 겉·속을 만드는 방식입니다. 스파인은 중앙과 별도 이미지로 배치하며 하나의 후보를 양쪽 접힘 영역에 사용합니다.

인쇄 대화상자에서 **A4, 실제 크기·배율 100%, 머리글·바닥글 해제**를 확인하세요. 용지에 맞추기와 프린터 자동 축소를 끄고 화면의 재단·접기 안내를 따르세요. 첫 출력은 자로 치수를 확인하는 것을 권장합니다. 프린터 여백·색상과 실제 케이스에 따라 차이가 날 수 있습니다.

## 완성 CD 미리보기

케이스 열기·닫기, 회전·이동·확대, CD 제거, 트레이 보기로 조합을 확인할 수 있습니다. 조작은 인쇄 설정이나 앨범 파일을 바꾸지 않습니다.

현재는 호환 미리보기가 기본입니다. 이미지 기반 앨범은 `정밀 미리보기 시도`로 WebGL 모형을 불러올 수 있습니다. 보이지 않으면 간단 미리보기로 전환하세요. 정밀 모형의 실제 브라우저·GPU 시각 검증은 아직 완료되지 않았으며 반사·투명도·색상의 실물 재현을 보장하지 않습니다.

## 저장 위치와 백업

기본 위치는 `~/CDstudio-library/`입니다. 앨범별 폴더에 `project.json`, `tracks/`, `assets/`, `artwork/`를 보관합니다. 코드 저장소와 사용자 앨범 데이터는 별개입니다.

작업이 끝난 뒤 서버를 종료하고 **라이브러리 폴더 전체**를 복사해 백업하세요. 메타데이터만 복사하면 음원·이미지가 빠집니다. `CDSTUDIO_LIBRARY`로 다른 저장 위치를 지정할 수 있지만 기존 파일을 자동 이동하지는 않습니다.

## 선택 설정

필요한 경우 서버 실행 전에 환경변수를 설정하세요. 실행 중인 작업에는 소급 적용되지 않습니다.

| 변수 | 의미 / 기본값 |
| --- | --- |
| `CDSTUDIO_LIBRARY` | 앨범 저장 경로 / `~/CDstudio-library` |
| `CDSTUDIO_CODEX_BIN` | Codex 실행 경로 / PATH의 `codex` |
| `CDSTUDIO_IMAGE_CODEX_MODEL` | 이미지 작업용 Codex 모델 / 앱에서 별도 지정하지 않음 |
| `CDSTUDIO_IMAGE_TIMEOUT_MS` | 이미지 작업 제한 / 900000ms(15분), 유효 범위 30000~900000ms |
| `CDSTUDIO_DESIGN_ENGINE` | 기존 HTML 디자인 엔진 / `codex` 또는 `claude`, 기본 `codex` |
| `CDSTUDIO_CODEX_MODEL` | 기존 HTML 디자인용 모델 / `gpt-5.6-sol` |
| `CDSTUDIO_CLAUDE_BIN` | 기존 HTML 디자인용 Claude 경로 / `/opt/homebrew/bin/claude` |

이미지 스튜디오는 사용자 Codex 설정을 무시하고 ChatGPT 로그인 상태를 확인합니다. 모델을 선택한다면 해당 계정에서 지원되는 모델이어야 합니다.

## 문제가 생겼을 때

- **yt-dlp 설치·검증 실패:** Python과 네트워크를 확인하고 `npm run setup:yt-dlp`, `npm run check:yt-dlp`를 다시 실행하세요. 전역 업데이트만으로 앱 전용 파일은 바뀌지 않습니다.
- **다운로드 HTTP 403:** 앱은 최대 3회 시도합니다. 계속 실패하면 원본 URL의 접근 가능 여부와 플랫폼 지원 상태를 확인하세요. 플랫폼 변경·접근 제한으로 모든 영상의 추출을 보장하지는 않습니다.
- **Codex 연결 오류:** 서버를 실행하는 터미널에서 CLI 경로와 `codex login status`를 확인하세요. CLI 연결과 실제 이미지 생성 가능 여부는 별개입니다.
- **이미지 파일 미생성:** 실제 PNG를 확인하지 못해 후보를 저장하지 않은 상태입니다. 표시된 사유와 진단 ID를 확인하세요. 일부 사유는 Codex의 자기보고로 원인을 독립적으로 확정한 것은 아닙니다. 생성되지 않은 파일은 복구할 수 없습니다.
- **안전 검사 차단:** 같은 요청을 반복해도 해결되지 않을 수 있습니다. 입력을 검토하거나 직접 이미지를 업로드하세요. 앱은 외부 안전 검사를 해제·우회하지 않습니다.
- **생성이 오래 걸림:** 단계와 경과 시간은 표시하지만 정확한 남은 시간은 제공하지 않습니다. 이미지 작업의 기본 최대 시간은 15분입니다.
- **3D 화면이 비어 있음:** 간단 미리보기로 전환하세요. 호환 모형 제공은 정밀 렌더링 문제의 완전한 해결을 뜻하지 않습니다.
- **인쇄 크기가 다름:** A4·100%·자동 축소 해제 설정과 프린터 여백을 확인하세요.

## 개발 및 검증

Next.js 16(App Router), React 19, TypeScript, Tailwind CSS 4 기반입니다. 외부 도구는 로컬 서버에서 실행합니다.

```bash
npm run test:unit
npx tsc --noEmit
npm run lint
npm run build
```

개발 서버의 빌드 파일과 분리하려면 `CDSTUDIO_TEST_BUILD=1 npm run build`를 사용하세요. 자동 테스트 통과는 실제 플랫폼 다운로드, 브라우저·GPU 렌더링, 프린터 출력, 실물 CD 굽기의 성공을 보장하지 않습니다. 실제 굽기는 사용자 확인과 공매체가 필요한 수동 검증입니다.
